如何理解这些统计？

平均抽数＝可见总抽数÷五星数量，包含首个五星与当前垫抽。“≥”表示前序不完整，只能确定下界；同一保底组会跨池累计，记录序号 80→1 视为连续。

已垫 X 抽表示自上次五星以来累计的可见抽数，不表示下个五星还差 X 抽。UP 未知时保留未知，不当成“歪”。

平均UP与五星平均均为该分类全部五星的平均间隔，包含歪出的抽数，不单独计算UP角色间隔。超欧/超非按首次UP概率分布的5%分位标记，已确认大保底和前序不完整不参与。

MANUAL CREDENTIAL
手动凭据教程
自动登录不兼容时，可以在电脑浏览器取得本人官网凭据。
  1. 在电脑打开官网并登录
    使用 Chrome 或 Edge 打开 https://i.haoplay.com.cn，确认网址后完成本人登录。
  2. 打开开发者工具
    在官网页面按 F12，选择 Application（应用）。
  3. 找到官网的本地存储
    展开 Local Storage（本地存储），选择 https://i.haoplay.com.cn。
  4. 复制完整的凭据值
    复制 jwt 的完整 Value，或 HP_2070021 / HP_2070023 的完整 JSON 值。不要只复制键名，也不要修改内容。
  5. 回到手机粘贴查询
    将值粘贴到登录卡背面的输入框，勾选本人确认后提交。只有查询成功才会清空输入。
凭据具有账号访问权限，不要发给他人、截图分享或附在问题反馈中。手机号和短信验证码不是这里需要的凭据。
