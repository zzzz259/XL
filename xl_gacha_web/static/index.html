    GETTING STARTED

    如何获取登录凭据

    在电脑端 Chrome 或 Edge 中操作。全程在官网完成登录，无需把短信验证码提供给本工具。

    1. 01

      打开官网，登录你的账号

      点击下方链接，确认地址是 i.haoplay.com.cn，然后自行完成短信或官网提供的登录流程。登录完成后，保持这个标签页打开。

      打开星落官方门户 ↗

      TapTap 账号也可使用 TapTap 官网入口 ↗。复制本次登录产生的值即可，不要修改 JWT 内容或应用 ID。

    2. 02

      按 F12，打开开发者工具

      在官网页面按 F12（部分键盘需要 Fn + F12），或右键页面选择“检查”。也可以按 Ctrl + Shift + I；Mac 使用 ⌘ + ⌥ + I。

    3. 03

      找到 Application（应用）面板

      在开发者工具顶部选择 Application（中文界面可能显示“应用”或“应用程序”）。如果没看到，点击顶部的 »，从隐藏面板中选择它。

      ElementsConsoleNetworkApplication»
    4. 04

      展开 Local Storage，选择官网地址

      在左侧找到 Storage（存储）→ Local Storage（本地存储），点击左侧小箭头展开，再选择 https://i.haoplay.com.cn。

      ▾ Storage　▾ Local Storage　　 https://i.haoplay.com.cn
    5. 05

      复制 jwt 的 Value（值）

      在右侧表格的 Key（键） 列找到 jwt，复制同一行 Value（值） 列的完整内容。优先右键该行，选择“Copy value / 复制值”；如果没有该选项，可双击值，再全选复制。不要只复制键名或截断的一部分。

      KeyValue
      jwteyJ…完整的登录凭据…
      HP_2070021{ "jwt": "eyJ…", … }

      也可复制 HP_2070021 或 TapTap 对应的 HP_2070023 的完整 JSON 值。本工具支持这两种格式，不需要复制其他条目或整张表格。

    6. 06

      回到本页，粘贴并查询

      将内容粘贴到“登录凭据”输入框，确认这是本人的账号，再点击“查询我的抽卡记录”。提交后输入框会清空；成功后可筛选记录或导出 CSV、JSON。

    没有找到 jwt？

    先确认官网已经登录成功，选择的是 Local Storage 而不是 Cookies / Session Storage，并且域名完全一致。必要时刷新官网页面后重新查看。若提示凭据失效，请在官网重新登录后复制新的值。

    可以在手机上获取吗？

    这份教程适用于电脑端开发者工具。手机浏览器通常没有相同的 F12 面板，建议先在电脑上操作。

    登录凭据包含账号访问权限，并非抽卡专用密钥。不要发到群聊、截图或公开分享，也不要复制手机号和短信验证码。
