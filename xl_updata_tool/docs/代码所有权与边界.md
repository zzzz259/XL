# 更新工具代码所有权与边界

此表用于定位日常改动的默认归属。模块职责详见[架构与协作基线](架构与协作基线.md)；跨子项目协作按仓库[贡献指南](../../CONTRIBUTING.md)执行。

| 领域 | 主要目录 | 边界 |
|---|---|---|
| 版本与下载 | `app/features/versions/`、`app/platform/downloader.py` | 版本展示、检查、下载计划和 Bundle 状态；不处理 AssetStudio 内容 |
| 导入与后处理 | `app/features/importer/` | 导入规格、Bundle 筛选、AssetStudio 执行、结果分类和后处理调度 |
| 预览与图像导出 | `app/features/preview/` | 预览索引、FGUI/Spine/视频处理及游戏素材；`data/material` 到 `output` 的转换契约需与导入方一起审查 |
| 音频 | `app/features/audio/` | 索引、分类、增量解包、播放、未读状态和音频输出 |
| 角色 | `app/features/characters/` | Lua 角色解析、结构化数据、图鉴页面和 CSV |
| 平台能力 Platform | `app/platform/` | 路径、文件、数据库、网络、子进程、日志、诊断和外部工具定位 |
| 装配与公共 UI Shared | `app/bootstrap/`、`app/shared/`、`app/shell/` | Feature 注册/启动、共享契约、导航、全局任务宿主 |
| 兼容 UI | `app/ui/` | 仅保留现有 Shell 与已登记兼容入口，不在旧入口增添新领域行为 |
| 自动化 | `tests/` | 纯逻辑、契约和回归；真实外部工具/GUI 还需按开发指南人工验收 |

## 依赖规则

1. 领域 service 和纯逻辑不依赖 PySide6；Qt Worker 只管理线程、取消、进度和结果信号。
2. Feature 不直接导入其他 Feature 的内部实现；跨域通过共享契约、结果对象或显式后处理注册表协作。
3. Shell 不直接处理资源解析、下载计划、音频目录扫描或导出策略。
4. 外部进程经平台/Feature adapter 调用，路径和参数集中构造；不通过字符串拼接 shell 命令。
5. `app/core/` 已退出当前生产结构。旧 `app/ui/` 模块仅按现有兼容引用维护，不新建同类兼容层。

## 需要跨域审查的改动

以下改动在 PR 中说明消费者、迁移影响和回滚方式，并增加覆盖边界的测试或 smoke：

- `app/platform/`、`app/bootstrap/`、`app/shared/`、`app/shell/`；
- `data/`、`output/`、数据库 schema、未读状态或索引格式；
- Importer 后处理类别、跨 Feature 结果对象、Worker 取消/进度约定；
- SpineViewer/AssetStudio/FFmpeg 的命令参数、工具定位和资源归档格式。

普通 Feature 改动尽量限制在一个 Feature 及其测试。避免机械式全仓格式化和与任务无关的路径迁移。
