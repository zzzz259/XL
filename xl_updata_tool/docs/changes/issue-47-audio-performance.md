# Issue #47 变更摘要

## 面向评审

- 新增 `AudioCatalogIndex`，把音频目录扫描结果转换为可查询的 Qt-free 层级索引。
- 新增 `AudioCatalogWorker`，启动后后台预热目录，版本列表不等待音频列表。
- 音频树改为首层目录和展开层级懒加载，降低首屏 Qt 节点数量。
- 选择状态由逻辑文件名集合维护，目录勾选和 Ctrl 多选不再依赖当前可见节点数量。
- 延迟处理点击后的复选框状态提交，避免 Qt 默认切换覆盖控制器状态。

## 不在本次范围

- 不修改 debank、音频分类、播放器格式和 output/audio 目录契约。
