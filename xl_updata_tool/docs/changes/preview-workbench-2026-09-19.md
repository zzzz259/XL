# 图片预览工作台与 Spine 导出收口

## 面向评审

- 图片预览页拆分为角色 Spine、角色导出立绘和游戏素材三个工作区，读取导入后生成的索引与 `output` 成品。
- 角色资源按角色编号、资源类型和皮肤身份组织；角色与 `bg` 部件通过 SpineViewerCLI 原生 `merge` 一次导出。
- 默认导出按资源类型分流：`cardspine` 生成静态 PNG 和完整动画 MP4，`battlespine` 使用 `motion_stander` 生成静态 PNG；默认 MP4 与 PNG 放在同一个角色目录。
- 自定义导出保留传统图片/视频及高级参数，仅允许恰好一个可见皮肤，避免多皮肤共享手工参数产生歧义。
- FGUI、BurstHead、LotteryBg、PassportPic 等游戏素材在导入后处理阶段切割/发布，预览页不再首次切页时执行重型处理。
- 未读状态、目录角标、分页和文件夹返回路径统一由预览状态与输出浏览器维护。

## 兼容与非目标

- 旧的 `output/video/` 独立视频导出入口保留兼容；新的图片预览默认导出不再写入该目录。
- `data/material/` 继续作为可重建来源目录，原始 Spine 资源同时发布到 `output/spine/`，不会被图片成品覆盖。
