### Codex 对话中已确认的长期需求

#### 1. 环境、打包和仓库卫生

- 项目内存在 `.venv` 时，开发、测试和 Python 包安装必须使用项目 Python；Java、.NET、FFmpeg 等非 Python 工具按系统/发布环境约定处理。
- 运行脚本不能写死个人绝对路径；`run.bat`、`debug.bat` 应适配其他机器，个人路径和本地临时配置不能提交。
- 需要检查并支持 FFmpeg、SpineViewer 所需 .NET 8、AssetStudio.GUI 所需 .NET 9，以及完整可打包构建环境；发布包通过 bundled runtime/tool locator 解析，不把代理或“梯子”当成软件运行前提。
- `data/` 是可重建的临时/来源材料，`output/` 是最终交付；原始资源和派生成品都保留，避免用户只能在软件内部看到而无法在资源管理器核对。
- 子项目脚本放在对应子项目范围内；项目根目录、`docs` 和输出目录不混入 `superpowers`、pytest 临时目录、缓存或其他杂项。

#### 2. 版本检查、下载和 AssetStudio 导入

- 检查更新、刷新、下载和导入任务都要防止重复点击；下载按钮在运行时显示百分比/进度，点击可取消，刷新/检查更新显示旋转图标和动态省略号且不可取消。
- 状态区同时显示大类阶段进度、当前类别进度、数量进度和当前文件名；底部一行作为简化实时状态日志。
- 下载失败、WinError 10061、代理配置和连接错误必须通过日志给出可定位原因，不能要求用户为了启动离线功能开启代理。
- Lua 单独导入必须只处理命中的 Bundle，不因未勾选音频/图片而扫描无关资源；导入弹窗后自动接续角色、音频和图片后处理，并保持可取消、失败保留旧产物和清理临时目录。

#### 3. 音频和角色数据

- 音频树递归显示 `album`、`voice` 及其中间目录的未读状态；末端文件、父目录和顶层页签状态向上聚合，全部已读后立即刷新，不依赖重启。
- 勾选/查看/播放是未读清除入口；目录选择使用逻辑选择集，普通点击互斥，Ctrl 才多选；后台预热和懒加载避免切页卡顿。
- 音频处理保留中日语音隔离、bank 精准筛选、BGM/debank/fsb 回退、增量缓存、取消、日志和最终 `output/audio/` 契约。
- 角色 Lua 按版本留存和增量解析，角色 ID 补充名称，旧版本可作为解析回退；角色缓存、未读同步和角色图鉴优化应能被图片预览复用。

#### 4. 图片预览工作台与资源识别

- 图片预览分为“角色 Spine”“角色导出立绘”“游戏素材”三页；页签名称只出现一次，移除无用的关闭预览、旧筛选和分页控件。
- AS 解包完成后立即处理图片资源，不把图集切割、索引建立和素材识别拖到首次切换图片页；页面只读取已发布索引，避免每次切页全量加载。
- Spine 按角色 ID、资源家族和皮肤身份匹配，不能依赖不规范文件名；角色与背景部件属于同一个皮肤。角色树显示为“角色 → 皮肤”，不把 default、动作、表情或背景拆成多余层级。
- `cardspine` 表示角色立绘皮肤，`battlespine` 表示战斗小人，`eventcovers` 显示为“活动封面”；编号、角色名和战斗小人序号必须从包内索引/同版本 Lua/角色图鉴可靠解析。
- 原始 Spine 文件发布到 `output/spine/`；角色最终 PNG/MP4 发布到 `output/character/<角色>/`；FGUI、BurstHead、LotteryBg、PassportPic 等游戏素材发布到 `output/game_material/`。`data/material/` 继续作为可重建来源。
- FGUI 图集通过包内索引、资源类型和关联纹理智能识别，不假设一定存在 `.atlas`；兼容 `.skel.bytes`、`.atlas.txt`、`.prefab`、`.asset` 等 AssetStudio 产物，并排除 `_n` 等法线贴图。图集必须自动裁剪，游戏素材页展示裁剪后的图，而不是原始图集。
- 角色立绘和游戏素材用项目配色的大图标文件夹浏览，提供返回上级、懒加载缩略图和大图标右上角“新”角标；Spine 用留出足够宽度的树形勾选列表。
- “新”状态从末端资源向文件夹、子集和顶层页签一路聚合；图片/素材页全部已读和进入查看后的清除必须即时同步，立绘/游戏素材在用户查看并返回上级后默认清除。

#### 5. Spine 默认导出与自定义导出

- 角色与 `bg` 必须作为同一皮肤一次传给 SpineViewerCLI 的 `merge`，导出一张完整立绘；不能先分开导出再依赖 UI 拼接。
- 默认配置只有一个入口，由资源类型自动处理：
  - `cardspine`：静态 PNG + 完整动画 MP4；静态图默认 4 倍、游戏内 idle 动作、尺寸上限 16000、10 像素边框、预乘 Alpha、透明底、第一帧、自动边框；视频默认 1 倍、`#7f7f7f` 背景、由动画自身决定时长和帧数，不传固定 duration。
  - `battlespine`：只导出静态 PNG，默认 1 倍、`motion_stander` 表情，其余沿用立绘的透明底、边框、预乘 Alpha、第一帧和自动边框规则；不导出视频。
  - `eventcovers`：按活动封面导出静态资源。
- 自定义导出是传统参数模式，先选择图片或视频，再调整同一套参数；高级设置折叠且可滚动，限制为仅勾选一个可见皮肤，避免多皮肤参数歧义。
- 角色立绘的 PNG 与 MP4 必须在同一角色目录，不单独创建 `video` 目录；动画导出使用完整动画时长，不能把探测到的时长当作用户指定截断值。
