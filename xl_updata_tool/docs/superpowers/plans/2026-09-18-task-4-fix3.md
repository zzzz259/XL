> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Burst Head 导出以可校验的逐条 sidecar 记录恢复，处理 source/fingerprint 更新、保存失败重试和输出冲突，并保持 metadata 与 split_atlas 兼容。

**Architecture:** sidecar 是每个目标的可靠持久记录，manifest 是可重建的聚合索引。加载时校验 manifest、sidecar 及目标之间的 source/fingerprint/output 关系，并按 output 检测多来源冲突；当前 source/fingerprint 优先复用匹配 sidecar，manifest 保存失败不会影响重试幂等性。

**Tech Stack:** Python 3、pytest、Ruff、现有 `material_catalog.py` 与 FGUI atlas API。

**Spec:** Task 4 第三修正轮用户要求及提交 `5b801006` 最终复审意见。

## Global Constraints

- 旧输出保留；重试复用同一新目标，不因旧 manifest source key 而跳过新 fingerprint。
- source、fingerprint、output 不一致或多个来源映射同一 output 必须返回 failed/diagnostics。
- 保持 metadata 分类行为与 `split_atlas`/`split_atlas_to_package_dir` 兼容。
- 最终运行项目 Python 的 focused/全量 pytest 与 Ruff，并提交一个修正 commit。
