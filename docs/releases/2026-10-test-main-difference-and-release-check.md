## 复刻表自动更新的准确行为

- 更新服务处理一个**新游戏版本**时，会从该版本的 Lua 数据重建卡池历史/队列并生成版本快照；不是每天按现实日期重画同一版本。
- 卡池历史与预测队列来自新版本资源；当前期次、开始/结束时间和“已确认”标记来自人工确认的 `rerun_schedule.anchor`。进入新期时应先核实并更新这个锚点及 `history_through_gacha_id`，否则自动生成的图仍可能使用旧的当前期。
- 排期解析或渲染失败不会阻断角色数据更新，但会保留 last-known-good；此时新版本数据可能显示为旧快照并带过期提示。
- 当前 test 已有来源版本 `134359843258232660` 的排期快照。当前 main 没有 `rerun_schedule/current.json`；仅部署代码不会补算已处理过的版本。因此 main 上线前需针对 main 当前版本补建一次快照并验证 Bot 查询，否则不要发布“正式群已可使用”的公告。
