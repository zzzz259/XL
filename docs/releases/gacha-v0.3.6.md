# 星落抽卡手记 Android v0.3.6 更新公告

这次汇总 0.3.4 之后的更新，主要完善渠道登录和查询。此前 0.3.5 测试功能统一并入 0.3.6，UI 和信息优化留到后续 0.4。

- 新增 B 服支持：通过官方哔哩哔哩 App 确认授权，自动识别账号并查询，无需手填 UID，也不需要 root 或读取游戏文件。
- 新增 TapTap App 授权：可使用手机上已登录的 TapTap。官网选择 TapTap 后，点击「打开 TapTap App」，确认后返回手记，继续完成官网授权，再自动查询；仍保留网页登录。
- 修复部分真实手机一直显示「正在准备授权」的问题；准备失败时提供重试和网页登录提示，授权确认后仍需手动切回手记。
- 增加卡池查询回执，区分空记录和查询失败；提供不含账号凭据的脱敏诊断，方便反馈问题。
- 官服与 B 服存档分开保存；保留 0.3.4 已有的账号切换清理、QQ 回流、相册保存和多图分享。

正式包沿用原包名和签名，0.3.4 用户直接覆盖安装，已有存档保留。独立测试版与正式版不共享数据，可先导出 JSON 再导入正式版。

正式构建的内部版本号为 14，可覆盖此前同包名的修复测试包，版本名称仍为 0.3.6。

**电脑端正式停止维护与更新，最后版本为 0.3.4。** 后续只更新安卓端，电脑端不再提供新包、修复和登录适配；旧记录可通过 JSON 迁移。
