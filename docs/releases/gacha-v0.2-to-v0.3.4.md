# 星落抽卡手记 v0.3.4 更新公告

汇总 0.2 以来的主要改进：

- 安卓长图支持保存至相册，或通过系统分享至 QQ、微信等应用；支持多选、批量与逐张操作。分享使用临时图片，不额外存入相册。
- 修复连续记录被误判“前序不完整”、垫抽清零及五星间隔低估的问题。平均抽数按可见总抽数÷五星数量计算，包含首个五星和当前垫抽。
- 配置地址默认内置，支持独立更新角色、卡池与保底规则；失败时继续使用本地配置。
- 电脑端增加浏览器检测、自定义路径、启动失败自动切换和环境自检，减少误报登录窗口关闭。
- 安卓修复导出0字节、查询新账号仍使用旧凭据的问题，新增“登录其他账号”。
- QQ 授权进入浏览器后，可分享网页至“抽卡手记·继续QQ授权”完成登录。

升级前建议备份。Windows 完整解压并迁移 user-data；安卓直接覆盖安装，不要卸载旧版。

记录保存在本机，支持多账号和 JSON/CSV 导入导出，无开发者云端存档上传。
