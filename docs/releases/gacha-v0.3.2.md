# 星落抽卡手记 v0.3.2 更新公告

这次把 0.2 之后的几次更新整理到一起，电脑端和安卓端包体均以 v0.3.2 标注。安卓新增了导出、切换账号和 QQ 授权修复；电脑端包含此前的统计、浏览器兼容与配置更新改进。

## 抽卡统计修正（0.2.1）

- 平均抽数改为“当前分类的可见总抽数 ÷ 五星数量”，包含第一个五星和当前垫抽。
- 修复记录序号从 80 回到 1 时，被误判为前序不完整的问题。不再因此清零真实垫抽，五星间隔和跨池累计会正确保留。
- 已保存的记录会按新规则重新计算，不需要为了修正统计重新登录查询。

首个可见五星、真正缺失的记录仍会保守标注“≥”或前序不完整。工具只能统计本机累计保存的可见历史，不保证覆盖账号全部生涯。

## 电脑端登录兼容改进

- 浏览器检测增加注册表、PATH 和自定义路径支持。
- Edge 启动失败时会尝试其他可用浏览器，Chrome 也会尝试回退。
- 分别检查浏览器进程和调试连接，增加重试与本机诊断日志，减少把连接暂时异常误判为窗口关闭的情况。
- 新增启动环境自检，提前检查浏览器、存档目录权限、本机端口和官方服务连接。

## 角色、卡池配置独立更新（0.3.0）

- 新增“游戏配置”更新入口，只下载小型角色与卡池 JSON 配置。
- 新配置可以重新识别已有记录中的角色名称、星级和卡池规则，原始抽卡记录保留。
- 支持启动后台检查、手动检查和本地缓存；下载或校验失败时继续使用原有配置。

发布前修订：默认配置地址将内置到包体，用户仍可修改。此前已交付的0.3.2候选包地址为空，需要待修订包替换。配置更新只更新角色和卡池数据，程序功能更新仍需安装新版本。

## 安卓导出与账号切换修复（0.3.1）

- 修复系统提示保存后，导出文件实际为 0 字节的问题。
- Android 10 及以上的 JSON、CSV、PNG、ZIP 导出统一保存到“下载/Starfall”；Android 9 保留系统文件选择器。
- 修复新登录仍读取上一个账号凭据、无法查询第二个账号的问题。
- 新增“登录其他账号”按钮。切换账号会先清理官网旧状态，再等待本人完成登录；已有抽卡存档不会因此删除。

## 安卓 TapTap → QQ 登录修复（0.3.2）

- 补充 QQ 授权链接和 `intent://` 跳转处理，修复工具拦截 QQ 唤起链接的问题。
- 支持可信授权页在点击后的连续跳转。
- 无法唤起目标应用时显示提示，便于检查 QQ/TapTap 是否安装在同一设备、同一用户空间。

第二账号切换已由用户复测确认。后续复测发现：QQ能唤起，但授权后进入外部浏览器，无法继续应用内TapTap登录；该完整链路尚未通过，修订包仍在处理。

## 升级与数据保存

升级前建议先“备份全部”。

- **Windows：**完整解压新包，保留并迁移旧程序旁的 `user-data` 文件夹到新程序旁。不要只复制 EXE，`_internal` 文件夹也需要保留。
- **Android：**直接覆盖安装正式 APK。包名和签名沿用原版，不需要先卸载；卸载或清除应用数据会删除本地存档。
- 独立 QA 测试应用与正式版不共享存档，需要通过 JSON 导出、导入迁移。

记录仍保存在本机，支持多账号、导入导出和长图。工具没有开发者云端存档上传或账号同步功能；配置下载也不会附带登录凭据、UID 或抽卡记录。
