# 星落抽卡手记 Android v0.4 更新公告

0.4 主要重做手机端的信息与界面，保留官服、B 服和 TapTap 授权查询，以及本机多账号存档。

- 页面调整为「记录 / 查询 / 我的」，查询进度直接显示在页内，账号、配置与备份更集中；支持多档字号。
- 账号优先显示游戏昵称，渠道放在小字中；修正头像裁切和头像框叠加，放大角色大头照，UP 头像移到池名旁。
- 新增生涯、近 45 天评价及十连多金、连 UP、连大保底等标签。普通池不参与或打断 UP 连数；超非按先歪再出 UP 的完整周期判断。
- 重新适配 1080px 长图，调整 Logo、统计和角色排版；支持具体卡池多选、保存相册与系统分享。
- 内置最新角色与卡池配置，补入菲欧、「信念辉光」「极道剑豪」及现有可获取的新头像素材。
- 客户端已预留角色头像、时装头像和头像框自动更新能力；待服务端上线下发后，可更新这些素材，无需再装新包。

升级前建议备份 JSON。正式包沿用原包名与签名，直接覆盖安装，**不要卸载旧版**。记录保存在本机，没有云端存档；统计仅基于已获取的历史。电脑端继续停止维护。
