星落抽卡手记 Android v0.4 更新公告

0.4 是从 0.3 系列升级而来的手机端信息与 UI 重构版本。

• 全新「记录／查询／我的」三栏，查看抽卡、登录更新和管理账号各有入口，返回时恢复浏览位置。
• 记录页重排昵称、UID、等级与总览，普通／限定／典藏分栏展示生涯、均抽与垫抽；卡池可分类筛选，五星间隔直观展开，原始明细保留搜索与分页。
• 新增生涯及近45天评价，回顾连UP、连大保底、连歪、满觉、十连多金与超欧／超非及高抽数出UP等生涯标签。
• 统一手机卡片、弹层与字号，账号以昵称为主，渠道作为小字；修正头像和头像框，UP头像移至池名旁，角色头像更清晰，加入可互动的gugu。
• 官服、TapTap、B服与手动凭据集中到查询页，完善登录进度、教程及失败反馈；「我的」统一管理账号、备份和导入导出。
• 长图采用独立1080px排版，支持卡池多选、预览、自动分张、保存相册、系统分享及ZIP导出。
• 更新内置角色、卡池与可获取素材；头像等资源已预留自动更新接口，待服务端接入后可免换包更新。

沿用原包名和签名，可覆盖安装保留本机存档。升级前建议备份JSON，请勿卸载旧版。
