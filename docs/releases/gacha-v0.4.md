# 星落抽卡手记 Android v0.4 更新公告

从 0.3 系列到 0.4，这次更新的重点是**手机端信息组织与 UI 的整体重构**。在已有的登录查询、本机累计存档和导出能力基础上，重新安排页面、统计与操作入口，让查看记录、更新账号和整理分享各有清晰的位置。

- **全新的三栏结构。** 底部导航调整为「记录 / 查询 / 我的」：记录页集中展示抽卡结果，查询页负责登录与更新，我的页面管理账号、备份、导入导出和游戏配置。首次使用直接进入查询，已有存档时进入记录；切换页面与返回时保留浏览位置。

- **围绕查看记录重新组织信息。** 首屏先展示玩家昵称、UID、等级与头像，再呈现总抽数、五星数量、卡池数量和抽卡生涯。普通、限定、典藏分栏展示抽数、出卡情况、平均抽数与当前垫抽；卡池按类别切换，五星记录直接展开，用横向间隔条展示抽数，并标出 UP、歪、大保底及前序不完整。角色收获可统一展开，原始明细集中到页面下方，保留搜索、筛选和分页。

- **新增抽卡生涯与高光回顾。** 根据本机已保存的历史，提供总生涯与近 45 天评价，识别十连双金、三金等多金记录，以及连 UP、连大保底、连歪、满觉角色和高抽数出 UP 等标签。符合条件的 UP 记录展示超欧／超非标记，普通池不参与 UP 连数计算。样本较少、星级未知或前序不完整时保留相应提示，所有评价只用于回顾可见记录。

- **面向手机重新打磨视觉与操作。** 统一调整卡片、间距、按钮和弹层，减少次要文字对主要数据的干扰。引入游戏角色头像、玩家头像与头像框，UP 角色头像紧邻池名；账号标题优先显示游戏昵称，渠道与存档别名放在小字中。新增 80%～140% 多档字号和可点击互动的 gugu，兼顾不同屏幕与阅读习惯。

- **重整登录与账号管理体验。** 官服网页、TapTap App、B 服授权及手动凭据入口集中在查询页，登录和查询进度直接在页内展示。手动凭据使用翻面卡片，获取教程单独打开，失败时保留输入。每次发起登录使用新的官网会话，不再提供保留官网登录状态的选项。顶部可随时切换本机账号，改名、删除、备份和导入导出集中到「我的」；原有渠道隔离、记录累计与重复去重能力继续保留。

- **重新设计长图与分享流程。** 长图采用独立的 1080px 排版，重新安排 Logo、账号信息、生涯统计、角色和五星间隔。可按分类或具体卡池选择导出范围，预览生成结果，超长内容自动分张；原有相册保存、系统分享和 ZIP 导出整合到同一面板，支持多图选择与批量处理。

本次同步更新内置角色、卡池配置和现有可获取的头像素材。角色与卡池配置继续支持独立更新；客户端也已具备头像、时装头像和头像框资源更新能力，**待服务端上线下发后**，这些素材可随配置更新，无需为新增图片重新安装 APK。

0.3 系列已有的官服、B 服与 TapTap 查询、本机多账号存档、JSON/CSV 导入导出及相册分享能力继续保留。本次更新面向 Android，沿用原包名与正式签名，覆盖安装可保留已有存档。升级前建议备份 JSON，**不要卸载旧版**；记录仍保存在本机，没有云端存档。
