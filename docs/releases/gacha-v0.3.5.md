- 已验收 0.3.4 发布工作树提交 `5402df97`，相册/分享功能提交 `a66209d7`；完整导入 Android 和 Windows/Web 客户端文件及配套文档、测试、公共配置生成器。
- 在此基础上重新叠加已有 B 服官方 App 授权、自动 SDK 身份交换、历史查询、渠道隔离存档和脱敏回执。
- 保留 0.3.4 的实际站点存储清理与轮询门控、登录其他账号、QQ 分享回流、Downloads 导出、相册保存、系统分享、默认配置地址。没有用版本号变更代替代码合并。

## 本轮验证

- Windows/Web Python 测试 82 项通过；公共配置生产器 9 项通过、1 项 Windows 不适用权限测试跳过；配置发布集成 4 项通过；Android 工具链 Python 测试 2 项通过。
- Android JS 引擎 9 项和长图 JS 5 项通过；Wire、B 服协议 JVM 测试通过。
- MuMu Android 实际 JSON：配置 76 项、登录链接 16 项、QQ 回流策略 15 项通过。
- 隔离 WebView 注入合成旧状态：新登录清理 8 项通过；QQ 回流独立/同任务各 12 项通过；真实相册/分享/Downloads 导出 20 项通过。
- 独立测试应用从 401 覆盖升级至 402 后保留两个账号，已有官服存档仍为 243 条记录、1746 抽。默认不记住会话打开新登录，官网来源无旧 JWT/HP，手记停在等待授权，没有自动查询旧账号。
- 合并后再次完成官方 B 站授权、自动身份交换、游戏认证和查询；四个选择器均返回 0，测试 B 服账号仍为空历史，没有重复新增账号。配置资产经页面请求为 404。

测试版本 `cn.starfall.gacha.bilitest` / `0.3.5-bili-test` / versionCode 402。原正式应用 `cn.starfall.gacha.local` / 0.3.4 / 8 保持原样。完整源码整合在当前工作区，尚未提交、推送或正式发布。

实体手机 B 服非空历史、更多设备和 Android 9 相册权限分支仍待验收。TapTap 复用 App 登录的研究可行性证据保留，本轮没有增加该入口；0.4 仍用于 UI 和信息优化。

## 合并之后：TapTap App 授权测试

用户确认后，已在上述基线上接入 TapTap App 授权入口，测试版本为 `0.3.5-tap-test` / 403，包名与原渠道测试包相同。官网选择 TapTap → 产品按钮打开官方 App → 本人确认 → 返回原网页授权 → 查询和归档，MuMu 实测四池成功返回 243 条记录、1746 抽。保留网页登录备用及脱敏诊断。

新流程 JS 4 项、Android 链接策略 21 项、真实 WebView/App 衔接 16 项通过；旧凭据清理 8 项、QQ 两种任务各 12 项、相册/分享 20 项回归通过。修正了隔离测试误认 `about:blank` 加载完成的等待条件。手机测试步骤见[用户指南](../gacha-user-guide.md)，实现边界见[TapTap 研究与接入记录](../research/taptap-app-login.md)。尚未提交、推送或正式发布。
